# Rizu Zaman Portfolio v10 — Cyber Glass / Spider Matrix

Upgrade tahap lanjut berbasis v9 dengan fokus:
- transparent interactive spider-matrix background
- animated multi-depth Spider-Man-inspired tech web frame
- full-frame profile presentation tanpa crop paksa (`object-fit: contain`)
- live Jakarta clock/date + Open-Meteo weather card
- global threat pulse UI dengan mode DEMO yang jujur dan optional verified ThreatFox integration
- interactive 3D telemetry globe
- pointer parallax dan reduced-motion support
- mobile-first responsive layout

## Verified threat telemetry
Set environment variable berikut di Vercel untuk mengaktifkan data ThreatFox:

`THREATFOX_AUTH_KEY=<your ThreatFox auth key>`

Tanpa key, dashboard tetap berjalan tetapi diberi label `DEMO TELEMETRY` dan tidak mengklaim sebagai serangan global real-time.

ThreatFox API docs: https://threatfox.abuse.ch/api/
Weather provider: Open-Meteo.
